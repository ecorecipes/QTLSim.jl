# Formal proofs

- `QTSimFast.lean`: the model of the two programs' algorithms and the proofs that they
  agree. It imports only Mathlib.
- `QTSimFastShadows.lean`: checks that the theorems say what is claimed (it imports
  `QTSimFast`).
- `QTSimFast.pdf`, `.html`, `.md` and `QTSimFastShadows.pdf`, `.html`, `.md`: the same
  files as documents, generated by `render.sh` (mdgen, https://github.com/Seasawher/mdgen,
  then Quarto; the PDF through typst). They are generated from the Lean files, state the
  SHA-256 of the file they were generated from, and are never edited by hand. Without
  mdgen, `render.sh` uses `lean2md.awk`, which writes the same format, and says so in the
  documents.
- `ModelCheck.lean`, `model_check.c`, `model_check_expected.txt`: the Lean model and the
  two C programs' own routines on one small instance (`make model-check` in the directory
  above for the C side; `check.sh` for the Lean side).
- `check.sh <Lake project with Mathlib>`: type-checks the two files standalone, prints the
  axioms the main theorems depend on, and runs `ModelCheck.lean`. Checked with
  `leanprover/lean4:v4.32.1` and Mathlib `v4.32.1`. By hand: put `QTSimFast.lean` in the
  root of a Lake project that depends on Mathlib and run `lake env lean QTSimFast.lean`.

The proofs are about a mathematical model, not about the C source: see `../PROOFS.md`.
