QTSimFast: the full parity matrix (./test_parity.sh full)

Run on the packaged code (fast/src and test_parity.sh as packaged; the Lean files, reports
and packaging were added afterwards and do not enter the programs), from the QTLSim.jl
layout, with the paper's input files at hand. macOS arm64 (Apple M3 Pro), Apple clang 21,
GSL 2.8, JOBS=4. Each comparison is cmp on standard output plus equal exit codes against
the original QTSim built from the unmodified source. Variant letters: t = threads,
p = threads forced on small inputs (2, 3, 4, 8), r = repeats with 4 threads, s = output on
the main thread, auto = QTSIM_THREADS=auto, b = block sizes (1, 5, 16, 64), l = one
individual at a time, g = collection every 50 generations, plain = no inlined generator,
no threads, no vector extensions, asan = AddressSanitizer + UndefinedBehaviorSanitizer,
tsan = ThreadSanitizer (a sanitizer report would count as a failure).

Without the paper's inputs (as in this package) the script uses synthetic inputs of the
same design instead of the 72 published option files; the other 385 option files are the
same.
