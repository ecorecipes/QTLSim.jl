QTSimFast: the full parity matrix (./test_parity.sh full)

1. THE REVISED CODE (the pipeline and the other changes of 19 November 2026; REPORT.md,
sections 3.9 to 3.13)

Run on the code as committed and packaged (fast/src and test_parity.sh), by make
parity-full, from the QTLSim.jl layout, with the paper's input files at hand. macOS arm64
(Apple M3 Pro), Apple clang 21, GSL 2.8, JOBS=4. The run took from the evening of 19
November to the next morning because the machine slept several times in between; nothing
was restarted. Each comparison is cmp on standard output plus equal exit codes against the
original QTSim built from the unmodified source. Variant letters: t = threads, p = threads
forced on small inputs (2, 3, 4, 8), o = the same with the pipeline off, x = the pipeline
with genotypes summed only after the mutations, y = with genotypes summed behind the draws
eight individuals at a time and the main thread always given a share, z = with threads
that sleep at once instead of polling, r = repeats with 4 threads, s = output on the main
thread, auto = QTSIM_THREADS=auto, b = block sizes (1, 5, 16, 64), l = one individual at a
time, g = collection every generation and every 50 generations, ps = GSL's plain
statistics calls, plain = no inlined generator, no threads, no vector extensions,
asan/asano/asany = AddressSanitizer + UndefinedBehaviorSanitizer with the pipeline on,
off, and in mode y, tsan/tsano/tsanx/tsany/tsanz = ThreadSanitizer with the pipeline on,
off, and in modes x, y, z (a sanitizer report would count as a failure).
