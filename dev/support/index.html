Support matrix

What QTLSim can run, and what has been checked against another backend, by feature, model, backend and closure of the moments lowering. Generated by scripts/support_matrix.jl from support_matrix() (ext/QTLSimCatlabExt/support.jl): every cell is a probe of the code (four generations of thirty individuals), so a cell is unsupported exactly where the lowering's own guard throws an ArgumentError, and a cell that runs is supported when the declared evidence names a validation script that compares it with another backend (QTSim, SLiM, the kernel or theory), untested otherwise. A test checks that this page is up to date.

✓ supported and validated · ○ runs, not validated · ✗ unsupported (a guard; see the note) · – not applicable. Columns: the kernel, the generated SLiM model (the probe generates the script; it does not run SLiM), and the moments lowering with each closure (loci; :auto picks one of them, see QTLSim.auto_closure and explain).
