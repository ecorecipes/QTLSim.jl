API reference

QTLSim.QTLSim — Module
QTLSim

A Julia port of QTSim, the quantitative-genetics simulation of Pagel, Gardner and Meade (Scientific Reports, 2025; the C source calls itself QTLSim 1.0): an additive polygenic trait under Gaussian stabilising viability selection toward an optimum that can move, with random mating, Poisson recombination and Poisson–Gaussian mutation. The kernel reproduces QTSim's numerics; validate/ compares it with QTSim and with the paper's published results.

The categorical layer, in which the population is an ACSet and the life cycle is a composite of operators (⋅) that can be stratified into demes (⊗), is the package extension QTLSimCatlabExt. Julia loads it when Catlab is loaded (import Catlab). Its functions are declared, documented and exported here.

source

Simulation

QTLSim.Params — Type
Params

Configuration for one simulation, with QTSim's defaults. Heritability is the narrow-sense heritability h² (a single scalar); MutationScalar is the mutation scalar m. The documentation's Parameters page lists every field with its meaning and its QTSim option. Values are checked when a World is made (see checkparams).

Two fields have no QTSim counterpart, or behave differently:

  • CrossoverModel: QTSim draws Poisson(RecombPoissonMean) crossover points per gamete but only the lowest one switches strands (its point index never advances), so a gamete has at most one crossover. :qtsim (default) reproduces that, as the published simulations did; :all applies every drawn point (the evidently intended Poisson-crossover model). With NoQTL == 1 the two are identical.
  • Drift: QTSim has the option but switches it off at the start of every run, so it never has an effect there. Here Drift = true makes every fitness 1: a neutral run, for comparison.
source
QTLSim.checkparams — Function
checkparams(p)

Throw an ArgumentError if p is not a model QTSim would run, or would run differently: Ploidy 1 or 2, at least one individual (two if diploid), locus, sampled generation and mutation per gamete; 0 ≤ Heritability ≤ 1 and PhenotypeVar > 0; MoveType one of :phenotype, :fitness, :continuous (QTSim falls back to the phenotype move on an unknown name; a misspelt symbol here would silently change the model); CrossoverModel :qtsim or :all; the schedules MoveFitnessSDGen and ChangeFitnessGen either −1 (off) or a generation, with ChangeFitnessSD > 0 when the width changes; and InitFitnessSD either −1 (the analytical width, which needs V_E > 0 and m > 0) or positive. Called by World(p).

source
QTLSim.World — Type
World

Mutable population state carried through the operators. Holds the current parents' genomes/environments, per-individual scratch (genotype/phenotype/ fitness), the survivor index set, the current selection optimum θ and width ω, and a double buffer (sgenome/senv) for the offspring generation.

Genomes are stored as (NoQTL, Ploidy, PopSize); the genotype of individual i is the sum over all its loci and chromosomes (QTSim CaclGenotype).

source
QTLSim.simulate — Function
simulate(p::Params; seed=p.Seed)

Run one simulation from Params with a MersenneTwister(seed), returning the recorded statistics (see run!) and the seed. Without a seed one is drawn at random, and the returned seed reproduces the run.

The same seed gives the same run with the same versions of Julia and Distributions.jl: the streams of rand(rng, 1:n) and of the Poisson sampler are not guaranteed across their releases.

source
QTLSim.run! — Function
run!(w, rng; record=true)

Iterate the generation operator for NoGenerations, replicating QTSim's RunSim order: develop → select → reproduce → (record) → fitness-width change → mutate → swap. Returns a NamedTuple of per-sampled-generation statistics (gen, pheno_mean, pheno_var, geno_var, nsurv, theta, omega) plus extinct/extinct_gen.

source
QTLSim.generation! — Function
generation!(w, rng; rec = nothing)

One generation of QTSim's life cycle, develop ⋅ select ⋅ reproduce ⋅ record ⋅ rescale ⋅ mutate ⋅ swap, advancing the offspring into the current buffer and w.gen by one; record appends to rec (see records) when one is given. A no-op past extinction. On a fresh World, call init_env! first: run! is init_env! followed by NoGenerations of these.

source
QTLSim.init_env! — Function
init_env!(w, rng)

Draw the founders' environmental deviations, N(0, V_E) each (QTSim CreatePop, via SetIndividualEnv). run! and run_composed do this first; a World made with World(p) starts with all deviations zero, so call it before driving a fresh World with generation! or the operators directly.

source
QTLSim.records — Function
records(; demes = nothing)

Empty columns for the statistics record! collects, as run! returns them; with demes, a vector of Worlds, also the deme of each row.

source
QTLSim.record! — Function
record!(rec, w)

Append the parent generation's statistics to the columns rec (see records) every Sample generations (QTSim Output); a no-op when rec is nothing. Variances are sample variances (n − 1), as GSL's. Besides QTSim's columns it records the mean fitness W̄ (one minus the load) and the selection differential, the survivors' mean phenotype minus the mean phenotype.

source
QTLSim.rescale! — Function
rescale!(w)

Change the fitness width to ChangeFitnessSD at the end of generation ChangeFitnessGen, so that it takes effect from the next generation (QTSim RunSim).

source
QTLSim.develop! — Function
develop!(w)

Genotype = Σ allele effects; phenotype = genotype + environment (QTSim CaclPopPhenotype). Deterministic given the environments drawn at birth.

source
QTLSim.select! — Function
select!(w, rng)

Move the optimum, assign each individual a stabilizing-selection fitness, and draw the survivor set (survive iff rand() < fitness). Mirrors QTSim Fitness

  • SetSurviving. Sets w.extinct if too few survive to reproduce.

Fitness is the normalized Gaussian pdf(Normal(0,ω), (z−θ)/sd) / (0.4/ω), replicating QTSim exactly (the 0.4 ≈ 1/√(2π) constant included); the idealized form exp(−(z−θ)²/2ω²) is what Lean StabilizingSelection.lean proves about.

source
QTLSim.moveoptimum! — Function

Move the optimum θ if the schedule says so (QTSim SetFitnessMean).

source
QTLSim.reproduce! — Function
reproduce!(w, rng)

Fill the offspring buffer sgenome/senv by fitness-independent random mating among survivors (QTSim NewIn). Haploid: clone a random survivor. Diploid: two distinct survivors each contribute a (recombined) gamete. Offspring get a fresh environment.

source
QTLSim.mutate! — Function
mutate!(w, rng)

Add Gaussian mutations to the offspring buffer (QTSim MutateIndividualChrNo). Each chromosome receives Poisson(L·rate) mutations, each of variance m/(ploidy·L·rate)·V_E; in expectation this injects m·V_E of variance per individual per generation (Lean mutationalVarianceInput_eq).

source
QTLSim.gamete! — Function
gamete!(dest, chrA, chrB, rng, recombMean, L, allpoints=false, pts=Int[])

Build one gamete from a parent's two chromosomes (QTSim CreateCombMap + RecombinationPoissonChr). Draw Poisson(recombMean) distinct crossover points in 0:L-2 (none if the count is 0 or ≥ L), start on a random parental chromosome, and switch strands after crossover points. QTSim never advances its point index, so only the LOWEST point switches: a gamete has at most one crossover. That is the default; allpoints=true switches at every point (Params CrossoverModel = :all). With L == 1 both reduce to picking one parental chromosome at random (Mendelian segregation).

source
QTLSim.swapbuffers! — Function

Swap the parent and offspring buffers (QTSim double-buffer swap).

QTSim options files

QTLSim.read_qtsim_options — Function
read_qtsim_options(path_or_io) -> Params

Read a QTSim options file into Params, as QTSim's PassOptFile reads it:

  • one Keyword value… per line, keywords case-insensitive;
  • a line whose first word starts with # is a comment;
  • MoveFitnessSD <generation> <size> and ChangeFitnessSD <generation> <width> take two values;
  • StandardisePhenotype and Drift take none and switch their option each time they appear.

The seed (Seed) goes into Params' Seed field. Note that QTLSim's random numbers are not QTSim's, so the same seed reproduces a QTLSim run, not the QTSim run.

Where the files differ from Params' field names:

QTSim keywordParams field
GenerationsNoGenerations
MoveFitnessSD g dMoveFitnessSDGen = g, MoveFitnessSD = d
ChangeFitnessSD g wChangeFitnessGen = g, ChangeFitnessSD = w
OptimumMoveTypeMoveType (:phenotype, :fitness, :continuous)
RecombinationPoissonMeanRecombPoissonMean

The other keywords (Sample, PopSize, NoQTL, Ploidy, PhenotypeVar, Heritability, MutationScalar, MutationRatePerGamete, InitFitnessSD, StandardisePhenotype) are field names.

Two rules differ from QTSim's:

  • An unknown keyword is an ArgumentError, as it is an error in QTSim. So is an unknown move type, which QTSim silently ignores, keeping the phenotype move.
  • Drift is read but dropped with a warning: QTSim switches drift off at the start of every run, so the option never has an effect there.

See also write_qtsim_options.

source
QTLSim.write_qtsim_options — Function
write_qtsim_options(path_or_io, p::Params; seed = p.Seed)

Write p as a QTSim options file, the inverse of read_qtsim_options: every option QTSim reads, with QTSim's keywords. The seed is written when there is one. QTSim cannot express two Params settings, so the file warns for them:

  • CrossoverModel = :all: QTSim applies only the lowest crossover point;
  • Drift = true: QTSim switches drift off.

Theory

The predictions the simulations are compared with; run_moments iterates them for any life cycle.

QTLSim.selection_variance — Function
selection_variance(p) -> V_s

The width of stabilising selection on the genotype, V_s = ω² + V_E, for the initial fitness width ω of p (initFitSD). Selection on a phenotype z = G + E with E ~ N(0, V_E) acts on G as Gaussian selection of variance ω² + V_E.

source
QTLSim.gaussian_vg — Function
gaussian_vg(p)

The Gaussian approximation to the equilibrium genetic variance under mutation–selection balance, √(V_m V_s), with V_m = m·V_E (muteVar) and V_s from selection_variance (Lande 1975). It ignores drift, and does not depend on the number of loci. The moments lowering (run_moments) has the slightly larger fixed point gaussian_vg_exact.

source
QTLSim.gaussian_vg_exact — Function
gaussian_vg_exact(p)

The fixed point of the Gaussian recursion V ← V − V²/(V_s + V) + V_m, which the moments lowering iterates: (V_m + √(V_m² + 4 V_m V_s))/2. It is √(V_m V_s)·(1 + O(√(V_m/V_s))), close to gaussian_vg when mutation is weak relative to selection (Lean gaussian_fixed_point).

source
QTLSim.effective_size — Function
effective_size(N, nsurv)

Falconer's effective size N_e = 4N/(V_k + 2) when nsurv of the N individuals survive and each of the next generation's 2N gametes comes from a survivor chosen at random: the number a survivor contributes is binomial, with variance V_k = 2N (nsurv − 1)/nsurv². With every individual surviving, N_e ≈ N.

source
QTLSim.house_of_cards_vg — Function
house_of_cards_vg(p; nsurv = p.PopSize)

Bürger's stochastic house-of-cards approximation to the equilibrium genetic variance, 4nμ V_s / (1 + V_s/(N_e α²)), with n loci, mutation rate μ per locus per gamete, α² = V_m/(2nμ) the variance of one mutation's effect, and N_e from effective_size with nsurv survivors per generation (Bürger 1989; the paper's Supplementary Figure S1). Unlike gaussian_vg, it grows with the number of loci.

source
QTLSim.steady_lag — Function
steady_lag(k; VG, Vs)
steady_lag(p; VG)

The lag θ − z̄ at which a population whose mean responds to Gaussian selection keeps pace with an optimum moving k per generation: k (V_G + V_s)/V_G (Lande; Bürger and Lynch 1995). The response to a lag λ is V_G λ/(V_G + V_s) per generation, which equals k at that lag (Lean steady_lag_response). With p, k = MoveFitnessSD and V_s = selection_variance(p), for MoveType = :continuous.

source
QTLSim.critical_rate — Function
critical_rate(; n, VG, ω, VE, sd50, N)

Bürger and Lynch's critical rate of environmental change, as the paper's results table computes it, in units of the phenotypic standard deviation sd50 at 50% mortality:

k_c = V_G/(V_G + V_s) · √(2 V_λ ln B₀),   V_s = ω² + V_E,  V_λ = V_s + V_G + V_s/(2N_e),
B₀ = N₀ ω/√V_λ,   N₀ = N(2n − 3)/(2n(n − 2)),   V_k = 2N₀(1 − 2N₀/N),  N_e = 4N/(V_k + 2),

where n is the number of survivors at the table's generation 10,047 and V_G the genetic variance just before the move. NaN where the table has none: n < 3, or B₀ ≤ 1. (The paper's equation 2 is printed without the factor 2 and with V_s + V_G for V_λ; this form reproduces its table to machine precision, see vignette 09.)

source
QTLSim.mutation_adjusted — Function
mutation_adjusted(rate, m, dist; w = ones(length(m)))

The paper's equation 1: each rate in rate weighted by the density of its population's mutation scalar m under dist (the paper's gamma distribution: the maximum-likelihood fit to all 119,984 mutation scalars, shape 1.201 and scale 0.004635), relative to the (w-weighted) mean density.

The categorical layer

These functions are implemented by the package extension QTLSimCatlabExt, which Julia loads when Catlab is loaded:

using QTLSim
import Catlab
using Catlab: ⋅, ⊗
L = lifecycle()                                                        # the life cycle as syntax
(; develop, select, reproduce, mutate, swap, generation) = operators()  # its image in the kernel

The life cycle and its lowerings

QTLSim.lifecycle — Function
lifecycle()

The life cycle as syntax: a named tuple of the Catlab presentation (presentation) of the free symmetric monoidal category whose objects are the stages of a generation (Zygotes, Adults, Survivors, Offspring), its generating steps (develop, select, reproduce, record, rescale, mutate, swap), QTSim's generation (generation), their composite develop ⋅ select ⋅ reproduce ⋅ record ⋅ rescale ⋅ mutate ⋅ swap, a morphism Zygotes → Zygotes, and migrate, where migrate(k) is the step that exchanges offspring among k demes, Zygotes^⊗k → Zygotes^⊗k. Composites type-check: a step can follow another only where the stages match. Catlab's ⊗ places life cycles side by side, one per deme: generation ⊗ generation ⋅ migrate(2) is a generation of two demes coupled by migration. lower gives a life cycle its meaning in a backend. Requires Catlab.

source
QTLSim.lower — Function
lower(f, target; images = Dict(), record = nothing, migration_rate = 0.0)

The image of the life-cycle morphism f under the lowering functor to target: :kernel gives an operator on a World, :eidos a fragment of Eidos code for SLiM, in which @POP@ stands for the deme's subpopulation, and :moments an update of the moments of a Gaussian population, the predictions of theory (see run_moments; one deme). A morphism between products of stages, one per deme, has an image on several demes: an operator on demes of a metapopulation (DemeOp), or Eidos for several subpopulations (EidosMeta). A functor out of a free category is fixed by the images of the generators, so the image of a composite or a product is the composite or product of the images. record steps in the kernel append the parent generation's statistics to record, a named tuple of vectors like the one run! returns, or discard them when it is nothing; migrate steps exchange individuals among demes at migration_rate (in Eidos, the constant migRate). Steps that are not in lifecycle, made with Catlab's Hom(name, dom, codom), need an image in images, keyed by name: an operator or a function (state, rng) -> state for :kernel, a string of Eidos for :eidos. Eidos steps keep a deme's state on its subpopulation: @POP@.getValue("THETA") and @POP@.getValue("OMEGA") are its optimum and fitness width, set with setValue, and the steps before select leave adults, genotype and pheno defined. Requires Catlab.

source
QTLSim.slim_script — Function
slim_script(f, p::Params; images = Dict(), migration_rate = 0.0)

A complete SLiM model, as Eidos source, that iterates the life cycle f, a morphism Zygotes → Zygotes, or Zygotes^⊗k → Zygotes^⊗k for k demes, each a subpopulation of p.PopSize individuals: the image of f under lower to Eidos runs once per tick in a reproduction() callback. The parameters of p and migration_rate are the defaults, which slim -d "NAME=value" overrides (N, VP, h2, m, rate, L, RECOMB, NGEN, sampleEvery, moveGen, moveSD, moveType, changeGen, changeSD, initOmega, drift, standardise, migRate). The Eidos images of the steps cover diploids (Ploidy = 2) with any number of loci, recombining as QTSim does (CrossoverModel = :qtsim); with several demes, each row of output ends with the deme. The life cycle must return each deme to its place: braidings must cancel. Requires Catlab.

QTLSim.run_composed — Function
run_composed(w::World, rng; record = true, cycle = lifecycle().generation, images = Dict())
run_composed(s, rng; cycle, record = true, images = Dict(), migration_rate = 0.0)

Run a simulation by applying the kernel image of the life cycle cycle, a morphism Zygotes → Zygotes, once per generation (lower; images gives the kernel images of steps that are not in lifecycle). Returns the statistics its record steps collect, as run! does; with the default life cycle, for the same seed, it is the same run as run!, bit for bit. For a metapopulation s = p ⊗ demes(k), cycle is a life cycle on k demes, such as g ⊗ g ⊗ g ⋅ lifecycle().migrate(3) for k = 3, and the statistics have a row per deme and sampled generation (deme), with extinct_gen per deme. Requires Catlab.

source
QTLSim.run_moments — Function
run_moments(p::Params; cycle = lifecycle().generation, images = Dict(), zbar = 0.0, VG = 0.0)

The life cycle cycle lowered to the moments of a Gaussian population (lower(cycle, :moments)) and iterated for NoGenerations: the deterministic, infinite-population predictions of quantitative-genetic theory for the same morphism the kernel and SLiM simulate. Each step's image updates the means and variances:

  • develop: V_P = V_G + V_E;
  • select: moves the optimum as MoveType says, then applies Gaussian selection of width ω to z ~ N(z̄, V_P). This gives the mean fitness, the expected survivors N·W̄, the selection differential, and the survivors' genotypic mean and variance z̄ + V_G λ/s and V_G − V_G²/s, with λ = θ − z̄ and s = ω² + V_P;
  • reproduce: passes those to the offspring (the continuum-of-alleles approximation, no drift);
  • mutate: adds m·V_E.

Returns the columns of run!, predicted (nsurv rounded). The genetic variance converges to gaussian_vg_exact; under a continuous move the lag θ − z̄ converges to steady_lag. The population is extinct when fewer than two individuals (one, if haploid) are expected to survive. One deme only. Requires Catlab.

Operators

QTLSim.operators — Function
operators()

The kernel images of the steps of the life cycle (lifecycle), as the named tuple (; develop, select, reproduce, record, rescale, mutate, swap, generation). An operator is called as op(world, rng), composes left to right with Catlab's ⋅ ((f ⋅ g)(w, rng) applies f then g), and acts deme by deme on a metapopulation built with ⊗. generation is the image of QTSim's generation, develop ⋅ select ⋅ reproduce ⋅ record ⋅ rescale ⋅ mutate ⋅ swap, in the order of its generation loop; here record discards what it observes (see run_composed). Requires Catlab.

QTLSim.operator — Function
operator(name::Symbol, act; scope = :deme)

A new operator that applies act(state, rng) and returns the state. With scope = :deme it acts on one population (a World) and is applied to each deme of a metapopulation; with scope = :meta it acts on the whole metapopulation, as migration does. Requires Catlab.

QTLSim.demes — Function
demes(k)

source
QTLSim.migrate! — Function
migrate!(s, rng; rate = 0.01)

Move individuals between the demes of a metapopulation s: each individual starts a swap with probability rate, exchanging places with a random individual of a random other deme, so the deme sizes are unchanged. Returns (; count), the number of exchanges. Requires Catlab.

rate is not the island model's migration rate m: an individual also moves when another deme's swap picks it, so with equal deme sizes about 2·rate of each deme is replaced per generation (each exchange moves two individuals). Use m/2 for an island-model rate m. The SLiM lowering (migRate) does the same.

Types of the extension

QTLSimCatlabExt — Module
QTLSimCatlabExt

The categorical layer of QTLSim, loaded with Catlab. The life cycle is a morphism of a free category whose objects are the stages of a generation (lifecycle.jl), lowered by functors to the simulation kernel, where each step is an Operator composed with Catlab's ⋅ and stratified into demes with its monoidal product ⊗ (compose.jl), and to a SLiM model in Eidos (eidos.jl), and to the deterministic recursions of quantitative-genetic theory on a Gaussian population's moments (moments.jl). The population is an attributed C-set (ACSet) on the schema of schema.jl. The facts that justify the decomposition, that composition is associative, that a run is the iterate of one composed generation and that a lowering is fixed by its action on the steps, are proved in lean/CategoricalQuantGen/Composition.lean and Lowering.lean.

source
QTLSimCatlabExt.Stage — Type

A product of stages, one per deme, as the image of an object under the lowering to backend B (:kernel or :eidos). The kernel carries each deme's stages in one World; in Eidos, a stage is the set of variables a step can rely on (EIDOS_SCOPE).

source
QTLSimCatlabExt.EidosCode — Type
EidosCode(name, code)

A fragment of Eidos, the image of a life-cycle morphism within one deme under the lowering to SLiM; @POP@ in code stands for the deme's subpopulation. The image of a composite is the concatenation of the images of its steps.

source
QTLSimCatlabExt.EidosMeta — Type
EidosMeta(n, perm, emit, name)

The image of a life-cycle morphism between tensor products of n stages, one per deme, under the lowering to SLiM: emit(pops) is its Eidos for the subpopulations pops, and output position i holds the deme at input position perm[i].

source
QTLSimCatlabExt.DemeOp — Type
DemeOp(n, perm, act)

The kernel image of a life-cycle morphism between tensor products of n stages, one stage per deme: act(s, demes, rng) acts on the demes s.demes[demes] of a metapopulation s, and output position i holds the deme at input position perm[i] (a braiding exchanges demes; the others leave them in place). ⊗ places operators side by side on consecutive demes, and ⋅ composes them.

source
QTLSimCatlabExt.Operator — Type
Operator(name, act, scope)

An evolutionary operator: op(state, rng) applies act(state, rng). scope is :deme for an operator on one population, applied to each deme of a metapopulation, or :meta for one on the whole metapopulation (migration).

source

Stratification into k demes, used as p ⊗ demes(k).

QTLSimCatlabExt.Stratified — Type

A metapopulation: demes (Worlds) that operators act on one at a time.

source
QTLSimCatlabExt.Population — Type

The population ACSet, with Float64 allele effects and traits.

QTLSimCatlabExt.Moments — Type

The state of the moments lowering: the parents' mean genotype (the mean phenotype, as environmental deviations have mean zero), genetic and phenotypic variances, the optimum and width, the expected survivors and mean fitness, the survivors' moments and the offspring's.
